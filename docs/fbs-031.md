# FBS 0.3.1 web support

Short share links are created from the object row or its metadata dialog. Random codes are the default. An alias, expiry, and inline or attachment disposition are optional. Choose Never to omit expiry entirely. Manage and revoke links from the bucket's Share links tab.

Sharing requires an admin credential backed by a stored user. The authentication bypass in server development mode cannot create links. Share links work without the public-read signing secret. Signed links remain available as an explicit alternative, require that secret, and obey the server's configured maximum duration.

A link follows the current object at its bucket and key. Overwrites change its content; deletion returns 404. Deleting the bucket removes its links. Deactivating or deleting the creator disables their links. Other services may retain media they copied before revocation.

Failed multipart completion offers Retry completion or Cancel upload. Retrying sends only the completion request using the same upload ID and part ETags. Cancellation aborts the upload. A missing upload cannot be retried. Recovery is limited to the current session; reloads do not restore uploads. If a completion response was lost after the server committed, a retry may report a missing upload. Refresh the object list to check the result.

Grant batches merge by grant ID, including existing grants returned for repeated requests. Mock mode validates the batch before storing anything and returns existing active grants for matching actions, grantees, and prefixes. Mock links model management operations but do not serve media.

Hard constraints: use Bun, Svelte 5 runes, TypeScript components, class-based context stores, and Tailwind. Keep existing work and sidebar animation behavior. Do not use `any`. Commit and push only when requested. Do not print or persist credentials in project artifacts. Keep the client SPA with SSR disabled.

Requested review: Gemini 3.8 Flash High through AGY in T3. The first review raised three findings. The expiry controls now use separate preset and custom state; browser checks confirmed clearing custom seconds keeps the field mounted and blocks submission. Signed links now support inline or attachment disposition through both clients. The suggested preload after creation was declined: the list loads on tab entry and refreshes when its cached bucket changes. Creating a link before first visiting that tab showed the current list correctly. The second independent review confirmed both fixes and the lazy-loading decision, and reported no remaining correctness findings. Both rounds used Antigravity model `gemini-3.8-flash-high` through T3 delegated tasks.

## Validation

- `bun test`: 15 passing behavior tests, including HTTP request mapping, grant idempotency and atomic failure, mock lifecycle, signed options, multipart retry, terminal errors, and cancellation.
- `bun run format`, `bun run lint`, `bun run check`, and `bun run build`: passed; type checking reported no errors or warnings.
- T3 browser against the local v0.3.1 SQLite/disk server: both share entry points, Never, alias conflicts, attachment headers and exact content, expiry and confirmed revocation returning 404, and custom signed downloads passed. Empty custom duration remains editable and invalid. Creator deactivate/reactivate/delete, overwrite, object deletion, and bucket deletion were checked through the real client and unauthenticated reads. Repeated grant batches returned the same IDs.
- A 9 MiB UI upload with an injected completion failure recovered through Retry completion: two part uploads, two completion attempts with the same upload ID, then HTTP HEAD 200 with the expected size and an updated object list. Cancel upload removed pending multipart state and left the key absent. Leaving the bucket route while waiting also removed pending upload state.
- At 390×844 and 320×568, tabs fit without page overflow; the share modal scrolls within the viewport. Desktop was checked at 1366×768.

Production deployment, external reverse proxies, third-party media previews, and browser reload recovery were not tested. The failed completion response was injected at the browser transport boundary; a conditional failure was not issued through browser CORS because the core's allowed headers exclude If-Match. Mock URLs do not serve bytes. Server development bypass behavior was checked in source and documented, not exercised as a separate live connection.
